## ⚡ Quick Start

### 1. Install Dependencies
Make sure you have Node.js 18+ installed. Run:
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
* The application will run locally at **`http://localhost:5173`**.
* The development server is configured with an API proxy inside [`vite.config.js`](file:///c:/Users/Sejal%20Jain/Downloads/ml-assisant/frontend-build/vite.config.js) to forward all `/api/*` endpoints to the FastAPI backend running at `http://127.0.0.1:8000`.
